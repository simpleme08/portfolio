# Simple — Portfolio

Personal portfolio for Simple, Software Engineer & Product Builder.

## Positioning
The site presents a professional engineering profile with a real HRIS product as the featured case study.

## Run locally
This is intentionally dependency-free: open `index.html` in a browser or serve the directory with any static web server.

## Before publishing
Replace the placeholder contact email in `index.html` with the preferred professional email address. Add verified employment history, education, certifications, additional projects, and measurable achievements only when they are accurate.

## Deploy
The site can be deployed to GitHub Pages, Render Static Site, Netlify, Vercel, or any standard static host.
